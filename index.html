Minimum Spanning Tree (MST)

This project demonstrates two famous graph algorithms used to construct the Minimum Spanning Tree (MST).

Algorithms

Prim's Algorithm

Starts from one vertex and repeatedly selects the smallest edge connecting a visited vertex to an unvisited vertex.

Kruskal's Algorithm

Sorts all graph edges and repeatedly selects the smallest edge without creating a cycle.

Time Complexity

Algorithm Best Average Worst
Prim's O(V²) O(V²) O(V²)
Kruskal's O(E log E) O(E log E) O(E log E)

Advantages

  • Efficient graph optimization.
  • Finds the minimum total edge weight.
  • Useful in networking, transportation, and circuit design.
